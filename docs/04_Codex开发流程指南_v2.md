# AI Career Copilot Codex开发指南

## 核心原则

Codex负责实现，你负责产品、架构和验收。

流程：

需求分析 → 设计 → 小模块开发 → 测试 → Review


## 调用Codex方式

每次说明：

- 项目目标
- 当前阶段
- 技术限制


要求：

1. 分析方案
2. 设计文件
3. 实现代码
4. 提供测试


不要一次生成完整项目。


## Review重点

检查：

- 模块化
- 可扩展性
- AI Provider是否可替换
- 数据安全
