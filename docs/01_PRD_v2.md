# AI Career Copilot Extension 产品需求文档（PRD）

## 产品定位

AI Career Copilot 是一个 Chrome 浏览器 AI 求职助手插件。

它不是招聘网站，而是用户浏览招聘网站时的 AI 求职副驾驶。

用户自行配置 AI API Key（DeepSeek、通义千问、OpenAI 等），插件调用用户自己的模型能力。


## 核心流程

安装插件 → 配置AI → 上传简历 → 生成职业画像 → 浏览岗位 → AI分析匹配 → 面试准备。


## MVP功能

### AI配置
- Provider选择
- API Key配置
- Model选择

### 简历分析
输入PDF简历，生成：
- 技能画像
- 项目优势
- 工作经历总结
- 职业方向

### 岗位分析
读取招聘页面：
- 公司
- 职位
- JD

输出：
- 匹配评分
- 推荐投递等级
- 优势
- 风险
- 简历优化建议

### 面试助手
生成：
- 技术问题
- 行为问题
- STAR回答
- 模拟面试
